A Windows tray icon for Claude Code. It tells you when a session finishes or is waiting on a prompt, and plays each project its own sound, so you know which one it was without looking.

One icon for every session

The most urgent session sets the icon's colour, and a number counts the sessions that need you, failed or finished while you were away.

All of them in one list

Hover the icon for a popup with each terminal session's project, branch, first prompt, and how long it has been working, waiting or done.

A sound per project

Each project gets its own tone and keeps it. A finished turn plays it once; a session that needs you plays it twice. Use the eight built-in tones, the Windows sounds, or your own files.

Click to jump

Clicking a row, a menu line or a toast brings that session's terminal window to the front.

Quiet when you want it

Do not disturb for 30 minutes, an hour or until 08:00, and a mute for any session. The icon and the list keep updating.

Careful with your settings

The hooks run async, so Claude Code never waits on them. The installer backs up settings.json before each write and touches only its own entries.

Everything stays on your PC.

No account and no telemetry. The hooks talk to the tray over 127.0.0.1, and nothing goes anywhere else.

  • Each hook call carries a token that changes every time the tray starts, so a web page cannot post fake sessions to it.
  • If the tray is closed, events wait in a local file and appear when it starts again.
  • Removing the hooks from the tray menu takes out only the entries it added.
